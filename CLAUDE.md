## PROJECT INSTRUCTIONS: PERSONAL WEBSITE AND BLOG

### CORE TECHNICAL CONSTRAINTS
- Zero JavaScript: Plain HTML and CSS only. Must function identically with JavaScript disabled in modern Chromium, Firefox, and Safari.
- Pure CSS Interactivity: Implement any UI toggles or states using native CSS techniques.
- Jekyll Builder & Tools: Use Jekyll as the static site generator. Build everything custom from scratch with zero prebuilt themes, templates or plugins.

### CODE STYLE
- Short comments are allowed in code files only if strictly necessary, keep clean of clutter otherwise.
- Maintain a clean, minimalist academic design and typography.
- Content priorities: Scientific work showcase, personal blog, and resume.

### WORKFLOW AND INTERACTION RULES
- Small Incremental Edits: Propose and make tiny changes one at a time.
- Clear Explanations: Explain each proposed change before asking.
- Approval Gate: Always get explicit approval before applying any modification.
- Local Testing: Run local deployment and testing via Jekyll to verify everything works properly before finalizing any change.
